Framing

Research question, hypothesis, concept

No separately authored thesis document exists in the repo yet. The framing below is derived directly from the grounded implications the audit scripts produced, not invented independently — treat it as a working draft, not a citable paper thesis.

Research question (derived)

Are medical-domain LLMs' answers reliable across reformulations of the same multiple-choice question — or does measured accuracy partly reflect sensitivity to answer-label format, option order, and answer-extraction convention rather than medical knowledge itself?

Working hypothesis (derived from dataset_audit.md §8)

Only roman_numeral (relabels A/B/C/D → I/II/III/IV) and fixed_pos (reshuffles option order) leave the question's meaning fully intact — a reliable model's answer should not change under either. The remaining four perturbations (open, no_symbols, incorrect, none_of_the_provided) each alter the task itself — output format, task definition, or which answer content is even available — and must be scored and reported as a separate "task-format / task-semantics" robustness category, never pooled with the meaning-preserving pair.

Concept

ReMedQA supplies the same underlying question in 7 formats across three source question banks (MedQA, MedMCQA, MMLU). CareQA, verified to have zero textual overlap with either, serves as an independent held-out validation set. Pairing perturbed variants back to their unperturbed original by shared id turns "did the model's answer change" into a directly measurable, per-question comparison.

Phase 0 proof of concept

Before spending any inference budget, this phase proves the data pipeline itself is trustworthy: ids pair correctly across all 7 perturbations (verified, not assumed), no dataset silently double-counts another, and a fixed-seed pilot cohort exists that any teammate can reproduce byte-for-byte from SEED=42.

05 · Phase 1A

Behavioral pilot — smoke test v2

Canonical answer-space scoring, ReAcc/ReCon, 3 real bugs found and fixed live (a mandatory Gemini thinking floor, a pandas invert bug, a schema-ignoring model), $0.0049 total cost, Claude still blocked by an account cap.

06 · Phase 1B

Validation + sensitivity check

Same 10 questions, no resampling. none_of_the_provided semantically audited before any call. Found a real Gemini thinking-budget instability under the harder perturbation — 50% truncation rate, root-caused from cached data at zero extra cost.

07 · Phase 1C

Generation-budget control

Same 10 questions, generous budget, 20 new calls: parse failures fully resolved (50%→100%) — but the fuller sample exposed Phase 1B's "100% accuracy" as survivorship bias. True rate: 85%, with one question missed identically by both models.

08 · Phase 2A

Framework validation · N=50 · single model

Reusable engine over all 7 representations: 350/350 evaluations, 0 parse failures, 0 truncations, exact QC agreement. Position vs semantic identity diverge sharply; open needs a semantic judge.

09 · Phase 3

Post-Training & Untouched Final Test

Unsloth GRPO post-training, 4-way leakage-safe split, 8,883 untouched final test evaluations, paired McNemar/Bootstrap hypothesis testing, publication figures and tables.

10 · SymRM Main Track Pilot

Symbolic Supervision for Neural Reward Models

Gate 2a Resubmission: 900 counterfactual vignettes across 10 rules, 0 banned tokens, raw-value diff invariance, Far-OOD BoW shortcut floor (50.0%), and hardware scaling on RTX 5060 (8GB).
