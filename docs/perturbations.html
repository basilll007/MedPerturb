What each ReMedQA perturbation actually changes

For a shared id, every perturbation's question/options/answer was diffed against the mcq baseline. Only two of the six are meaning-preserving — the other four each alter the task itself in a distinct way.

§1 · Perturbation semantics

Per-perturbation change log

Every cell below was verified by a scripted before/after diff, not by reading the paper's prose.

PerturbationWhat changesMeaning-preserving?
mcq Baseline: 4 lettered options, single-letter answer. baseline
roman_numeral Only option labels change, A/B/C/D → I/II/III/IV. Question, option text, and correct content are byte-identical. yes — relabel only
fixed_pos Option order is reshuffled; the answer letter tracks the move. Text and content unchanged. yes — reorder only
open Question is reworded into an open-ended, non-MCQ phrasing; options dropped from the prompt; answer becomes free text. no — rewords question
no_symbols Question text unchanged (verified — it does not reword like open). Options shown without A/B/C/D labels; answer becomes full option text. no — answer format only
incorrect Question/options unchanged, but the task is inverted: model must name the three incorrect options. no — task inverted
none_of_the_provided The correct option's text is overwritten with the literal string "None of the provided options"; that option stays labeled correct. no — removes correct content
CAUTION
incorrect is not a correctness target. Its raw answer field is a list of the three wrong letters (e.g. ['A','C','D']) — it inverts what's being asked rather than rephrasing the same question/answer pair. The pairing table sets perturbed_answer_interpretation = null and flags every such row with is_task_inverted = True so it can never be silently scored as a wrong answer.

§3 · Why this matters

Two buckets, never pooled

Meaning-preserving (robustness)

roman_numeral · fixed_pos

These test format- and position-robustness of the same medical knowledge. A reliable model should select equivalent content regardless of whether the label is A or I, or whether the correct option is listed first or fourth. Pooling their accuracy with the next bucket would mask format-sensitivity as genuine knowledge gaps.

Task-altering (separate analysis)

open · no_symbols · incorrect · none_of_the_provided

Each of these changes what the model is being asked to produce, or what content is even available. They must be scored and reported as a distinct task-format / task-semantics robustness category. incorrect inverts the task — "name the wrong answers" — and needs its own metric entirely.
