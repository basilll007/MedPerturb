§2 · Carried forward

What this means for the experimental design

Every item below is forced by the data audit — not a preference. Changing any of them requires arguing against the scripted findings on file.

  • Score meaning-preserving and task-altering perturbations separately. Pooling roman_numeral/fixed_pos results with open/no_symbols/incorrect/none_of_the_provided would conflate format sensitivity with task-definition sensitivity. Report two distinct robustness numbers per model.
  • Never treat local MedQA's test split as independent of ReMedQA. It is 98.9% the same 1,259 questions as medqa_mcq. Use MedQA's train split (10,178 rows, 0% overlap) if a larger or fresh MedQA cohort is needed. Validation split is also clean at 0%.
  • CareQA is safe to use as an independent validation set against both ReMedQA and MedQA — verified 0% overlap and 0 near-duplicates — but key it on unique_id, not question text, because of its own internal duplicate-stem groups.
  • fixed_pos's correct answer always lands at position D. Any position-bias study using this perturbation should account for the fact that it is a fixed target, not a uniform reshuffle. Compare directly against roman_numeral (0% position change) to isolate pure positional bias from label-format sensitivity.
  • Pairing must stay id-based everywhere — verified reliable for ReMedQA's 7-way family; MedQA (no id column) needs content-based joins instead, exactly as Task 5's overlap analysis already does. Never key ReMedQA on question text.
